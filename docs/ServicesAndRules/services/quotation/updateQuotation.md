# updateQuotation

Editar/Atualizar uma cotação por inteiro.

Este serviço é responsável por validar os dados recebidos, aplicar as regras de negócio e atualizar uma cotação no sistema.

## Objetivo

Editar uma cotação já existente, não apenas a cotação base, mas seus itens tambem.

As regras relacionadas à entidade podem ser encontradas em [Database](@Database) .
